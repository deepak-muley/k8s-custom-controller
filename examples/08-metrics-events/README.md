# Sample 08: Metrics & Events

This example demonstrates how to implement custom Prometheus metrics and Kubernetes event recording in a controller-runtime based controller.

## Features

### Custom Prometheus Metrics

1. **Counter Metrics**: Track total reconciliations
   - `monitored_reconcile_total`: Total reconciliations by result (success/error)
   - `monitored_threshold_exceeded_total`: Times threshold was exceeded

2. **Gauge Metrics**: Track current values
   - `monitored_current_value`: Current monitored value per resource
   - `monitored_active_total`: Total active Monitored resources

3. **Histogram Metrics**: Track durations
   - `monitored_reconcile_duration_seconds`: Reconciliation duration

### Event Recording

The controller uses `record.EventRecorder` to record Kubernetes events:

- **Normal Events**: ReconcileStarted, ReconcileSuccess, HealthCheck
- **Warning Events**: ThresholdExceeded, ProcessingFailed, StatusUpdateFailed

## CRD: Monitored

The `Monitored` CRD represents a resource being monitored with configurable thresholds and intervals.

### Spec Fields

- `target`: Target resource to monitor (required)
- `threshold`: Alert threshold 0-100 (default: 80)
- `interval`: Monitoring interval in seconds (default: 60)

### Status Fields

- `state`: Current state (Monitoring/Alerting/Healthy/Failed)
- `lastCheckTime`: Timestamp of last health check
- `reconcileCount`: Number of reconciliations
- `currentValue`: Current monitored value
- `observedGeneration`: Last observed generation

## How It Works

### 1. Metrics Registration

Custom metrics are registered with `metrics.Registry` in the `init()` function:

```go
func init() {
    metrics.Registry.MustRegister(
        reconcileCounter,
        reconcileDuration,
        monitoredGauge,
        thresholdExceededCounter,
        activeMonitored,
    )
}
```

### 2. Metrics Updates

Metrics are updated throughout the reconciliation loop:

```go
// Track reconciliation duration
defer func() {
    duration := time.Since(startTime).Seconds()
    reconcileDuration.WithLabelValues(req.Namespace, req.Name).Observe(duration)
}()

// Update gauge with current value
monitoredGauge.WithLabelValues(
    monitored.Namespace,
    monitored.Name,
    monitored.Spec.Target,
).Set(float64(currentValue))

// Increment counter on threshold exceeded
thresholdExceededCounter.WithLabelValues(
    monitored.Namespace,
    monitored.Name,
    monitored.Spec.Target,
).Inc()
```

### 3. Event Recording

Events are recorded using the EventRecorder:

```go
// Normal event
r.Recorder.Event(monitored, corev1.EventTypeNormal, "ReconcileSuccess",
    fmt.Sprintf("Successfully reconciled, state: %s", monitored.Status.State))

// Warning event
r.Recorder.Event(monitored, corev1.EventTypeWarning, "ThresholdExceeded",
    fmt.Sprintf("Current value %d exceeds threshold %d", currentValue, threshold))
```

### 4. Event Recorder Setup

The event recorder is initialized in `main.go`:

```go
if err = (&controller.MonitoredReconciler{
    Client:   mgr.GetClient(),
    Scheme:   mgr.GetScheme(),
    Recorder: mgr.GetEventRecorderFor("monitored-controller"),
}).SetupWithManager(mgr); err != nil {
    setupLog.Error(err, "unable to create controller")
    os.Exit(1)
}
```

## Building and Running

### Generate DeepCopy and CRDs

```bash
# From the examples/08-metrics-events directory
controller-gen object:headerFile=../../hack/boilerplate.go.txt paths="./..."
controller-gen crd paths="./..." output:crd:artifacts:config=config/crd
```

### Build the Binary

```bash
# From the repository root
go build -o bin/08-metrics-events ./examples/08-metrics-events
```

### Install the CRD

```bash
kubectl apply -f examples/08-metrics-events/config/crd/metrics.examples.k8s.io_monitoreds.yaml
```

### Run the Controller

```bash
./bin/08-metrics-events
```

The controller will start with:
- Metrics endpoint: http://localhost:8080/metrics
- Health probe: http://localhost:8081/healthz

### Create Sample Resources

```bash
kubectl apply -f examples/08-metrics-events/config/samples/monitored_sample.yaml
```

## Key Learning Points

1. **Metrics Registration**: Register custom metrics with `metrics.Registry` in `init()`
2. **Metric Types**: Use Counter for cumulative values, Gauge for current values, Histogram for distributions
3. **Metric Labels**: Use labels to add dimensions to metrics (namespace, name, target)
4. **Event Recording**: Use EventRecorder to record events that appear in `kubectl describe`
5. **Event Types**: Use Normal for informational events, Warning for issues
6. **Observability**: Combine metrics and events for comprehensive observability

## Common Patterns

### Tracking Success/Failure

```go
if err != nil {
    reconcileCounter.WithLabelValues(req.Namespace, req.Name, "error").Inc()
    r.Recorder.Event(resource, corev1.EventTypeWarning, "Failed", err.Error())
    return ctrl.Result{}, err
}
reconcileCounter.WithLabelValues(req.Namespace, req.Name, "success").Inc()
```

### Tracking Duration

```go
startTime := time.Now()
defer func() {
    duration := time.Since(startTime).Seconds()
    reconcileDuration.WithLabelValues(req.Namespace, req.Name).Observe(duration)
}()
```

### Recording Meaningful Events

```go
// Include context in event messages
r.Recorder.Event(resource, corev1.EventTypeNormal, "Updated",
    fmt.Sprintf("Updated %d replicas for target %s", replicas, target))

// Use appropriate event types
r.Recorder.Event(resource, corev1.EventTypeWarning, "ThresholdExceeded",
    fmt.Sprintf("Value %d exceeds threshold %d", current, threshold))
```

QUICK START FOR NEW SAMPLES:

2. Find/replace placeholders (RESOURCE, GROUPNAME, XX-sample-name)
3. Generate code:
   cd examples/XX-sample-name
   ~/go/bin/controller-gen object:headerFile="../../hack/boilerplate.go.txt" paths="./api/..."
   ~/go/bin/controller-gen crd paths="./api/..." output:crd:artifacts:config=./config/crd
4. Build: go build -o ../../bin/XX-sample-name main.go
5. Test: go test ./controller/... -v
